Create A Matrix From The Image

library(readr)
## Read the CSV file into a data frame
X <- read_csv('image1.csv')
## Convert data frame into a matrix
X <- data.matrix(X)

Function to Compress An Image Using PCA

compress_image <- function(X, k) {
  # X: n x p numeric matrix (the image)
  # k: desired rank of the approximation
  
  V <- t(X) %*% X
  
  # Eigendecomposition
  eig <- eigen(V)
  U <- eig$vectors        # p x p
  
  # Principal component scores
  Z <- X %*% U             # n x p
  
  # Rank-k approximation
  X_k <- Z[, 1:k, drop = FALSE] %*% t(U[, 1:k, drop = FALSE])
  
  # Frobenius norm
  err <- norm(X - X_k, type = "F")
  
  list(approx = X_k, error = err, U = U, Z = Z)
}

Plot Of Original Image vs. First 10 PCA Approximations

par(mfrow = c(3, 4))

# Original
image(
  t(X[nrow(X):1, ]),
  axes = FALSE,
  col = gray.colors(256),
  useRaster = TRUE,
  asp = 1
)
title("Original")

# k = 1,...,10
for (k in 1:10) {
  result <- compress_image(X, k)
  X_k <- result$approx
  
  image(
    t(X_k[nrow(X_k):1, ]),
    axes = FALSE,
    col = gray.colors(256),
    useRaster = TRUE,
    asp = 1
  )
  title(paste("k =", k))
}

Plot Approximation Error vs. k For All Possible k

p <- ncol(X)

errors <- numeric(p)

for (k in 1:p) {
  result <- compress_image(X, k)
  errors[k] <- result$error
}

plot(
  1:p,
  errors,
  type = "l",
  xlab = "k",
  ylab = "Frobenius Norm Error",
  main = "Approximation Error vs. k"
)
result = compress_image(X, 1)

u1 = result$U[, 1]
z1 = result$Z[ , 1]

par(mfrow = c(1, 2))

plot(
  u1,
  type = "l",
  xlab = "Column Index (Width of Image)",
  ylab = "Eigenvector Value",
  main = "First Eigenvector"
)

plot(
  z1,
  type = 'l',
  xlab = "Row Index (Height of Image)",
  ylab = "PC Score",
  main = "First PC Score"
)

*The first eigenvector represents the dominant pattern across the columns of the image. Each value describes how strongly a particular column contributes to the first principal component. The first PC scores represent how strongly that pattern is expressed in each row of the image. Together, the first eigenvector and first PC scores produce the rank-1 approximation of the image.*

Interpretation

The first eigenvector captures the strongest changes in brightness across the width of the image. For most of the columns, the eigenvector remains fairly stable with only small fluctuations, which corresponds to the relatively uniform gray portions of the image. The sharp change toward the right side corresponds to the bright vertical feature, showing that this boundary contributes strongly to the first principal component.

The first PC scores describe how strongly this horizontal pattern appears at each row of the image. Because the scores remain fairly consistent through much of the image, the dominant pattern captured by the first eigenvector is present across most of its height. The smaller variations in the scores reflect the noise and minor intensity differences between rows.

The approximation error decreases as k increases because each additional principal component allows the reconstruction to capture more of the original image. The error decreases quickly for the first few components and then begins to level off, showing diminishing returns as k increases. This is consistent with the image being relatively simple, since only a small number of components are needed to capture most of its structure.

Best Value of K

I think k=6 provides a sufficiently good approximation. Most of the important structure is already recovered by this point, including the major brightness regions and their boundaries. Beyond k=6, additional components mostly recover smaller variations and noise, so the visual improvement becomes less significant.

Interpretation

The first eigenvector shows how different horizontal positions contribute to the dominant brightness pattern of the image. The substantial variation across the eigenvector reflects the greater complexity of this image compared with Images 1 and 2. The first PC scores show how strongly this dominant horizontal pattern occurs at different vertical positions. The approximation error decreases more gradually for Image 3 than for the simpler images. Consequently, more principal components are needed before the error becomes relatively small. Around k=30, the curve begins to show diminishing returns, supporting the use of a higher-rank approximation for this image.

Best Value of K

I think k=30 provides a sufficiently good approximation. Unlike the simpler first two images, this image contains considerably more texture, edges, and fine detail, so substantially more components are required. By approximately k=30, the dog and the important features of the image are clearly represented, while further increases in k provide progressively smaller improvements in reconstruction error and visual quality.
